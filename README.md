# FB Clone Website

A Facebook-inspired social media website created as a **learning project** to practice web development and understand how real-world websites are structured.

This project is **not intended to be an exact copy of Facebook** or to replicate its backend, services, or proprietary features. The main purpose is to experiment with different web development concepts and improve my practical coding skills.

## 🎯 Project Purpose

I created this project to learn and practice:

* Building a website structure from scratch
* Creating a responsive user interface
* Working with HTML, CSS, and JavaScript
* Understanding how different website components work together
* Creating navigation bars, profiles, posts, buttons, and other UI elements
* Practicing Git and GitHub for version control
* Learning how to manage commits, branches, and project history
* Understanding how to upload and maintain projects on GitHub

## 🚀 Features

The project currently focuses mainly on the **frontend experience** and may include features such as:

* 🏠 Home/feed page
* 👤 User profile section
* 📝 Post interface
* ❤️ Like and interaction buttons
* 💬 Comment section
* 🔔 Notification interface
* 🔍 Search interface
* 📱 Responsive design
* 🧭 Navigation menu

Some features may be **UI-only** and are being implemented for learning purposes rather than as fully functional social-media features.

## 🛠️ Technologies Used
